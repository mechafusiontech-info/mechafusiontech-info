## 🔷 About MechaFusion Technologies

**MechaFusion Technologies** is an engineering design and creative studio based in **Vadodara, Gujarat, India**. We combine **mechanical design, robotics, electronics and media production**, so a client can get a part drawn, a prototype built and a video made from one team.

> **Engineering Ideas into Working Machines.**

- 🏢 Founded and led by **Dhiren Dhall** (Mechatronics, Parul University)
- 📐 CAD in **SolidWorks, AutoCAD, Fusion 360 and Solid Edge**
- 🤖 Robotics and **Arduino** prototypes, **PCB** design
- 🎬 Professional **video and photo editing**
- 🌐 Website: *coming soon*
